06 카메라

이 실험실은 어떻게 돌아가나요?

토리는 실제로 만들고 있는 도토리 로봇이에요. 걷는 법은 이미 따로 배웠고, 여기서는 0.2초마다 10가지 명령(앞으로, 옆걸음, 돌기, 멈춤…) 중 하나를 고르는 법만 배워요.

토리가 아는 것: 깃발 방향·거리, 지금 속도, 가까운 물건 5개의 위치·크기·푹신함, 앞쪽 거리센서 값. 모두 48개 숫자예요.

점수: 깃발에 가까워지면 +, 딱딱한 물건 가까이 가면 −, 부딪히거나 길(폭 1.4 m)을 벗어나면 크게 −, 깃발에 닿으면 +3. 양말·손수건은 밟아도 되지만 조금 −.

이곳은 빠르게 배우려고 만든 2D 연습장이에요. 물리 엔진(MuJoCo)처럼 다리·접촉 힘을 계산하지는 않지만, 몸 반응(명령별 속도·0.3초 늦음·좌우 흔들림)은 MuJoCo 속 토리에서 직접 잰 값을 써요. 여기서 배운 두뇌는 MuJoCo에서 진짜 걷는 토리에게 얹어 다시 확인해요.
